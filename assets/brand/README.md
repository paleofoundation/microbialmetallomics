# ORCID iD icon

`orcid-id.svg` is the unmodified official icon downloaded from:
https://orcid.org/assets/vectors/orcid.logo.icon.svg

Display guidance:
https://info.orcid.org/documentation/integration-guide/orcid-id-display-guidelines/

Display the icon as a link to its researcher's ORCID record. Preserve the original
artwork and use an accessible link label. The site's chosen presentation uses a
24-pixel icon without a visible numeric identifier.
